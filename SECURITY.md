# Security policy

Repo2OKF is pre-release software. Security fixes are made on the latest main
branch until stable release lines exist.

Please report vulnerabilities through the repository's
[private security advisory form](https://github.com/suisya-systems/repo2okf/security/advisories/new).
Do not include OAuth tokens, API keys, private source code or vendor CLI
authentication files in a report.

The runtime threat model and trust boundaries are documented in
[`docs/security.md`](docs/security.md).
